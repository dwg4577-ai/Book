알라딘 API 키
API 키는 이 기기의 브라우저에만 저장하고, 웹앱 파일에는 넣지 않아요.
API 키 발급 방법
1. 알라딘에 로그인해요.
2. OpenAPI 키 발급 페이지에서 이 웹앱의 GitHub Pages 주소를 등록해요.
3. 발급된 TTBKey를 복사해 위 입력칸에 붙여넣고 저장해요.

예: https://사용자명.github.io/저장소이름/
알라딘 API 키 발급 페이지 열기
알라딘 기본 OpenAPI는 개인의 비영리 목적 사용이 가능하며, 등록한 URL 기준으로 키를 발급받는 방식이에요.
백업 / 복원
책 기록을 JSON 파일로 백업하고 다시 불러올 수 있어요. API 키는 보안을 위해 백업 파일에 포함하지 않아요.
