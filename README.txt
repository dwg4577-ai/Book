책책책 📖 v2.2

변경 사항
- 홈 책더미의 각 책을 '가로로 눕힌 책 커버'처럼 보이게 변경
- 실제 표지 이미지를 가로 프레임에 맞춰 중앙 크롭
- 책 제목은 중앙 오버레이로 유지
- 책은 모두 수평 + 중앙 정렬
- 쪽수에 따른 높이 차이는 약하게 유지
- 기존 v2.1의 검색/월별 책더미/읽은 책 찾기/백업/팝업/확대 방지 기능 유지
