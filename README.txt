책책책 📖 v2.1

변경 사항
- 확대/핀치 줌 방지
- 홈 아이콘을 손으로 그린 듯한 펼쳐진 책 스타일로 변경
- 책 상세 팝업을 바텀시트 대신 중앙의 큰 카드형 팝업으로 변경
- 상세 화면 글씨/표지/버튼 크기 축소
- 닫기 버튼을 우측 상단 ×로 변경
- 최신 책이 항상 책더미 영역의 맨 아래, +책 쌓기 버튼 바로 위쪽에 보이도록 변경
- 책이 많아지면 과거 책을 보기 위해 책더미 영역만 위로 스크롤
- 월별 책더미에서 해당 월을 누르면 그 달에 읽은 책 목록 표시
- '🔎 읽은 책 찾기' 추가
  제목/저자로 내가 읽은 책을 검색 가능
- 서비스워커 캐시 갱신을 강화해 새 버전 반영 문제를 줄임
