책책책 📖 v2.4

변경 사항
- 책 종이 단면을 다시 왼쪽으로 이동
  실제 책처럼 얇은 페이지 층이 왼쪽에 보이도록 수정
- 책 전체 두께를 줄임
  150쪽 이하 약 29px / 300쪽 약 34px / 500쪽 약 39px / 800쪽 약 45px / 그 이상 약 49px
- 책 폭을 60~78%로 조금 더 좁힘
- 표지 가로 크롭 + 중앙정렬 유지
- 알라딘 검색 결과창을 더 넓고 여유 있게 복원
- 검색 중 안내를 가운데 정렬
- 검색 결과 표지/제목/여백 확대
- 검색 결과 최대 높이를 약 48vh로 늘림
- 홈 진입 / 책 추가 / 수정 후 가장 최신 책이 책더미 영역 위쪽 약 30% 지점에 오도록 자동 스크롤
