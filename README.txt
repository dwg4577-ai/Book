책책책 📖 v2.3

변경 사항
- 같은 책을 다시 선택하면 '전에 읽은 책이에요' 안내
- 이전 기록 보기 / 다시 읽기 선택
- 다시 읽기 시 이전 독후감들을 참고용으로 불러옴
- 재독할 때 이전 기록은 덮어쓰지 않고 새 회차로 저장
- 상세화면에 2회 읽음 / 3회 읽음 표시
- 읽은 책 찾기에 '다독한 책 🔁' 필터 추가
- 재독도 월별 권수에는 새 1권으로 카운트
- 새 책은 위로 쌓이는 방향으로 수정
- 책 폭을 64~82%로 줄여 더 귀엽게 조정
- 가로 표지 크롭 유지
- 책 아래에 종이 페이지 단면 느낌 복원
- 월별 책더미 색상을 파스텔톤으로 변경
