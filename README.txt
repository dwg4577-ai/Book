책책책 📖 v1.9

변경 사항
- 홈 전체 화면은 고정되어 위아래로 움직이지 않음
- 책더미 영역만 세로 스크롤 가능
- 앱을 열면 가장 최근 책이 화면 위쪽 약 1/3 지점에 보이도록 자동 위치 조정
- 책은 계속 수평/중앙 정렬
- 상단에 '이번 달 N권' + '총 N권' 표시
- 월별 책더미 추가
  - 읽은 책이 달별로 작은 책더미처럼 쌓여 보임
  - 가로 스크롤 가능
  - 가장 최근 달이 자동으로 보이도록 이동
- 설정 버튼 정렬 보정
- 기존 별점/백업/검색 기능 유지
